Elite Force for Mac @VERSION@ - Marino's Build (EliteForce-MacOS-Marino)
Star Trek: Voyager - Elite Force single player and Holomatch for Apple Silicon Macs.
https://github.com/marinohardin/EliteForce-MacOS-Marino

You need:
- A Mac with Apple Silicon (M1 or later) and macOS 12 Monterey or later.
- Your own copy of the game (GOG, Steam or CD + patch). No game data is included.

Install:
1. Drag "Elite Force.app" to your Applications folder.
2. Open it. (It's signed and notarized by Apple, so macOS opens it without warnings.)
3. In the launcher, click Choose... under Game Files and pick your Elite Force folder
   (the one containing BaseEF). Then pick Single Player or Holomatch and click Play.

LAN parties: everyone picks Holomatch. One person hosts (Host a Server in the launcher,
or Servers > Create Server in the game); the others find it under Servers > Local.
Allow "find devices on your local network" when macOS asks.

Co-op (EXPERIMENTAL, new in this version, Mac only): play the single-player campaign with a
friend. Click Co-op... on the launcher's Single Player card: one Mac clicks Host, the other types
the host's address and clicks Check, then Connect, to join as player 2. Both need this same
version and the same game files. Co-op uses UDP port 29760; for a friend on the internet, tick
"Open the port on my router" and send them the link from Copy Invite. Only the host saves. It is
new and lightly tested: please report glitches on the GitHub page above.

Cmd+W and the game window's close button now ask before quitting; Cmd+Q quits at once.

Holomatch includes cMod's game modules by Noah Metzger (Chomenor), with his kind permission:
a widescreen HUD, lag compensation on servers you host, and many fixes. Thank you, Noah.
